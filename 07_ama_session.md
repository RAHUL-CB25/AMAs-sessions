## AMA – Questions & Answers
1. What is a promise?

A Promise is a JavaScript object used to handle asynchronous operations. It can be pending, fulfilled, or rejected.

2. What is the status code for a bad request?

400 is the HTTP status code for a Bad Request.

3. What is a module?

A module is a file containing reusable code like functions, classes, or variables that can be imported into another file.

4. Why do we say Django is a framework?

Django is called a framework because it provides a complete structure and built-in tools for developing web applications.

5. What is the BASE_DIR?

BASE_DIR represents the root directory of a Django project. It is mainly used to create paths for files and folders.

6. What is hybrid inheritance?

Hybrid inheritance is a combination of two or more types of inheritance, such as multiple and multilevel inheritance.

7. What is UserCreationForm?

UserCreationForm is Django’s built-in form used to create a new user with username and password validation.

8. What is the sed command?

sed is a Linux command used to find, replace, delete, or modify text in files or input streams.

9. What is the difference between auto_now_add and auto_now=True?

auto_now_add sets the date/time only when the object is created. auto_now updates it every time the object is saved.

10. What is F in Django?

F() is used to refer to a model field directly in database queries, allowing calculations or comparisons without first loading its value into Python.
