Q1. Which command is used to clone a repository using the CLI?

We use git clone followed by the repository URL to download a full copy of it locally.

Q2. What is the rsync command used for?

rsync is used to copy and sync files between locations, and it only transfers the changed parts to save time.

Q3. How do we create an abstract class in Python?

We import ABC and abstractmethod from the abc module, inherit ABC in our class, and mark methods with @abstractmethod.

Q4. Which command is used to create a new Git branch?

We use git branch branch_name, or git checkout -b branch_name to create and switch to it in one step.

Q5. Why do we use git reset?

git reset is used to undo changes by moving the branch pointer back to a previous commit.

Q6. What is the difference between cp and rsync?

cp copies everything every time, while rsync only copies the changed parts and can also work over a network.

Q7. Which command is used to run an SQL file from the terminal?

We use mysql -u username -p database_name < filename.sql for MySQL, or psql -U username -d database_name -f filename.sql for PostgreSQL.

Q8. What is the alt attribute used for in HTML?

It gives a text description of an image, shown if the image fails to load, and it also helps accessibility and SEO.

Q9. Can we use multiple pseudo-classes together in CSS?

Yes, we can chain them together, like a:hover:not(.disabled), without any space in between.

Q10. What is the difference between Flexbox and Grid?

Flexbox works in a single direction, row or column, while Grid handles rows and columns together for full layouts.

Q11. What is the difference between Git and GitHub?

Git is a local version control tool, while GitHub is an online platform to host and collaborate on Git repositories.

Q12. What is the difference between append() and extend() in Python?

append() adds one item as a whole, while extend() adds each element of an iterable individually to the list.

Q13. What is the full form of ISP in SOLID?

ISP stands for Interface Segregation Principle, meaning classes should not be forced to implement unused interfaces.
