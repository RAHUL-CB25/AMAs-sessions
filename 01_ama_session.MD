### 1. What is Open/Closed Principle in SOLID?

A class should allow new features to be added without changing the existing code.

### 2. What is normalization in SQL?

Normalization means organizing data into different tables to reduce duplicate data and keep the data correct.

### 3. What is abstraction and encapsulation?

Abstraction means hiding unnecessary details from the user. Encapsulation means keeping data and methods together inside a class.

### 4. What is the kill command used for?

The kill command is used to stop or send a signal to a running process using its process ID.

### 5. What is LSP in SOLID?

LSP says that a child class should be able to replace its parent class without causing problems in the program.

### 6. What is the find command, and how is it used?

The find command is used to search for files and folders. Example: find /home -name "test.txt"

### 7. What is string slicing?

String slicing is used to get a part of a string. Example: "Python"[0:3] gives "Pyt".

### 8. What is ISP in SOLID?

ISP says that a class should not be forced to use methods that it does not need.

### 9. What is composition and why is it preferred over inheritance?

Composition means creating a class using objects of other classes. It is preferred because it gives more flexibility and makes the code easier to change.

### 10. What is method overriding in OOP?

Method overriding means a child class creates its own version of a method that is already present in the parent class.

### 11. How can you rename a file?

We can use the mv command to rename a file. Example: mv old.txt new.txt

### 12. What is the difference between the -i and -o flags?

The -i flag makes the search case-insensitive, while the -o flag shows only the part of the text that matches the search pattern.

### 13. What is the difference between a class method and an object method?

A class method works with the class and uses cls, while an object method works with an object and uses self.
