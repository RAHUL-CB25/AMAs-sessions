# AMA Questions and Answers

- **What is compaction?**  
  Compaction summarizes the conversation to free up context space while keeping the important information.

- **What are hooks?**  
  Hooks are commands or scripts that run automatically when specific events occur, such as before or after a tool is used.

- **What is the difference between Skills and Hooks?**  
  Skills provide reusable instructions for completing tasks, while Hooks automatically execute scripts when specific events happen.

- **What is a project?**  
  A project is a workspace for organizing related files, instructions, and tasks in one place.

- **What is generative AI?**  
  Generative AI is a type of AI that creates new content, such as text, images, code, or audio, based on user input.

- **What is the difference between a search engine and agentic AI?**  
  A search engine finds information from the web, while agentic AI can plan tasks, use tools, and take multiple steps to achieve a goal.

- **What is Cowork?**  
  Cowork is Anthropic’s AI workspace that helps users complete multi-step tasks using files and connected tools, with less manual effort.
