# AMA Questions 

- **What are HTTP methods?**  
  HTTP methods define the action to perform on a resource, such as `GET` to fetch data, `POST` to create data, `PUT` to update data, and `DELETE` to remove data.

- **What is `Promise.any()`?**  
  `Promise.any()` returns the first successfully fulfilled promise and ignores rejected promises unless all promises fail.

- **What is the `SELECT` statement in SQL?**  
  `SELECT` is used to retrieve data from a database table. We can use it to fetch specific columns or all columns using `SELECT *`.

- **What is currying?**  
  Currying is a technique that converts a function with multiple arguments into a sequence of functions, each taking one argument at a time.

- **What is encapsulation in OOP?**  
  Encapsulation means wrapping data and methods into a single class and controlling access to the data using access modifiers.

- **What is Celery?**  
  Celery is a Python task queue used to run background tasks asynchronously, such as sending emails or processing large files.

- **What is the difference between `git pull` and `git fetch`?**  
  `git fetch` downloads updates from the remote repository without merging them into your current branch, while `git pull` fetches the updates and integrates them into your current branch.
